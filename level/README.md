"" Вопрос 1. Почему LRU не подвержен аномалии Белади, а FIFO подвержен? ""

Ответ:

LRU является стековым алгоритмом. При увеличении количества кадров набор страниц, находящихся в памяти, сохраняет свойство вложенности. Поэтому количество отказов не увеличивается.

FIFO не учитывает частоту и давность обращений к страницам. Поэтому увеличение количества кадров иногда меняет порядок вытеснения неудачным образом и приводит к увеличению числа отказов.

Вопрос 2. Чем Major Page Fault отличается от Minor Page Fault?

Ответ:

Minor Page Fault возникает, когда процессу необходимо обновить таблицу страниц, но чтение данных с диска не требуется.

Major Page Fault возникает, когда для получения необходимой страницы требуется операция ввода-вывода, например чтение данных с накопителя.
